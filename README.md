# Taha AI — Multi-Model Chat Website

Powered by **OmegaTech APIs** (no API keys required).

## Features
- 🧠 5 chat models: Claude, Gemini Premium, GPT-4o-mini, Qwen3 80B, Gemma Code
- 🖼️ Image editing (GPT Image Edit)
- 🎨 Image generation (Flux)
- 💬 Session-aware chat
- 🌙 Dark UI, mobile responsive

## Requirements
- **Node.js 18+**

## Run
```bash
npm install
npm start
# Open http://localhost:3000
